# Resurser

Bra ställen att fortsätta lära sig, ladda ner verktyg och hitta plattformar att jobba på.

## Lär dig mer

| Resurs | Vad det är |
|--------|-----------|
| [Learn Git Branching](https://learngitbranching.js.org/) | Interaktiv övning — visualiserar branches och commits i realtid medan du kör kommandon. Det bästa sättet att faktiskt förstå rebase och merge. |
| [GitHub Git Cheat Sheet](https://training.github.com/downloads/github-git-cheat-sheet/) | Githubs officiella snabbreferens — en sida med de vanligaste kommandona. Bra att ha uppe i ett fönster. |

## Ladda ner Git

| Plattform | Länk |
|-----------|------|
| Windows / Mac / Linux | [git-scm.com/downloads](https://git-scm.com/downloads) |

Git för Windows installeras enklast via [winget](https://winget.run/pkg/Git/Git): `winget install Git.Git`

## Plattformar — var bor ditt repo?

Git är ett lokalt verktyg. En plattform är dit du pushar och delar repot med andra. De är inte samma sak — se [Git ≠ GitHub](grunder/git-vs-github.md).

| Plattform | Vem äger den | Passar |
|-----------|-------------|--------|
| [GitHub](https://github.com) | Microsoft | Open source, de flesta privata projekt, studenter (GitHub Education) |
| [dev.azure.com](https://dev.azure.com) | Microsoft | Företag i Microsofts ekosystem, Azure DevOps-pipelines |
| [GitLab](https://gitlab.com) | GitLab Inc. | Team som vill ha allt i ett (CI/CD, issues, registry) — kan self-hostas |
| [Codeberg](https://codeberg.org) | Ideell förening (Tyskland) | Open source-projekt som vill ha en etisk, EU-baserad plattform |

Alla stödjer Git — du klonar, pushar och pullar likadant oavsett vilken du använder.
