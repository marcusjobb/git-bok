# Konflikter

En merge-konflikt uppstår när Git inte kan slå ihop två versioner av samma fil automatiskt. Det ser skrämmande ut första gången — men det är inte farligt. Git har inte kraschat, Git väntar bara på att du ska fatta ett beslut den inte kan fatta själv.
